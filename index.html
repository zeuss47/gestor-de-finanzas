Zona peligrosa

Borra gastos, ingresos, tarjetas, cuentas y metas — local y en el repo de GitHub si tenés Sync configurada. Mantiene tu PAT y la configuración de Sync para que no tengas que reconectar.

Tipos de cambio

Editá las cotizaciones desde el widget Tipo de cambio en el dashboard.

Sin configurar —

Configurá GitHub para sincronizar entre dispositivos.

¿Cómo configurarlo? (paso a paso)

1. Andá a github.com/new y creá un repositorio privado (ej: finanzas-data).

2. Andá a github.com/settings/tokens/new y generá un token con scope repo.

3. Pegá el token y el nombre del repo abajo. La app sincroniza sola cada 5 min y al cerrar pestaña.

✓ Tu PAT se guarda solo en este dispositivo, jamás se sube al repo.
